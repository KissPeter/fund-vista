In this repo use Serena's code-intelligence tools, not shell grep/cat, for anything code-related: find_symbol / get_symbols_overview / find_referencing_symbols to navigate, search_for_pattern to search, replace_content (regex, with wildcards) or replace_symbol_body to edit, list_dir / find_file to browse. Shell is fine for git, docker, and non-code files (yml, md, sh). The user asked for this explicitly on 2026-10-21. Serena's tools also cover shell scripts and markdown through search_for_pattern/replace_content (they are not indexed as code symbols, so symbolic edits do not apply there). Always check find_referencing_symbols before renaming or changing a symbol's signature.
