Drawscape two-phase rendering vs fund-vista static SVG. Full note: docs/drawscape-two-phase-rendering.md. Drawscape preview = slippy vector map (MapLibre + Mapbox Streets v8 MVT tiles); zoom detail comes from pre-generalized tiles per zoom, pan fetches neighbor tiles, layer checkboxes are style filters. Final render reproduces from bounds+zoom+layers server-side. Ours = single Overpass live query to static SVG (no zoom generalization). Free equivalent path: OpenFreeMap tiles + client-side MapLibre preview, backend only for final render.
